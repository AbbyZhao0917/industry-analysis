## 十五、信息检索技巧

1. **搜索格式**：`<关键词> site:<网站>` 限定来源
2. **文件类型搜索**：`<关键词> filetype:pdf` 找研报
3. **时间限定**：搜索工具中限定近1年/近1月
4. **公众号搜索**：微信搜一搜找行业KOL分析文章
5. **研报标题模式**：搜索"<行业名> 深度报告"或"<行业名> 年度策略"
6. **招股书搜索**：在巨潮资讯网搜索"<公司名> 招股说明书"

## 使用优先级

在做行业/企业分析时，按以下优先级引用数据源：

1. **招股书/年报**（最权威、最详实、免费）
2. **国家统计局/行业协会**（宏观与行业数据）
3. **券商研报**（深度分析，东方财富可免费获取）
4. **咨询公司报告**（行业洞察）
5. **专业数据库**（金融/消费/科技等细分数据）
